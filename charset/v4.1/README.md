# FFTA2 V4.1 最终字表

本目录提供美版《最终幻想战略版 A2》V4.1 汉化的默认字形编号、游戏文字编码与 Unicode 对照。以已交付的 1.0.6 clean 和 plus 核对，保留V4.1继承的全部既有编号；字表版本与ROM程序版本分别标记。

## 下载

- [glyphs.csv](glyphs.csv)：完整对照表，UTF-8 BOM，方便表格软件查看。
- [glyphs.json](glyphs.json)：完整对照表和字段类型，适合程序读取。
- [decode.tbl](decode.tbl)：已登记字位的 `游戏编码=字形标签` 对照，供解码参考。
- [扩展字位、MOD／输入法与字库容量](FONT-LAYOUT.md)：共享尾部规则、ROM文件位置和实测剩余空间；[结构化数据](font-layout.json)。
- [SHA256SUMS.txt](SHA256SUMS.txt)：本目录文件的SHA-256校验值。

## 编号范围

| 默认字形编号（从0开始） | 内容 | 游戏编码 |
| --- | --- | --- |
| 0–167 | 西文、数字及原生符号，共168字位 | 单字节 `01`–`A8` |
| 168–3117 | 原有中文及双字节符号，共2950字位 | 双字节 `A900`–`B485` |
| 3118–3131 | V4新增、V4.1继承的13个字位；3124未登记 | 按各行记录 |
| 3132–3135 | 道具底栏专用的「道具情报」紧凑字形别名 | `B494`–`B497` |
| 3136 | 普通汉化版追加字「驳」 | `B498` |
| 4367 | 日期分隔线专用字形，与「—」对应 | `B967` |

文件逐行保留 **4368个默认字位编号**。其中3137个有已登记字形标签，3131个有单个Unicode码点；6个原生特殊字形保留命名标签，不猜测Unicode。其余1231字位标记为 `unmapped_do_not_encode`，**未登记不表示空白或可重新分配**。

尾部由普通追加、MOD及专用字形共同管理；输入法候选复用已有汉字编号，提示字形另占追加范围。预约和剩余空间的完整边界见[扩展说明](FONT-LAYOUT.md)。

选择不同字体不会改变编号。这里公开字符映射，不包含字体像素、字库二进制、游戏译文或ROM数据。

## 字段

| 字段 | 含义 |
| --- | --- |
| `glyph_id` | 默认字形编号，十进制、从0开始 |
| `game_code_hex` | 游戏文字编码，以十六进制书写；双字节按高字节在前排列 |
| `byte_length` | 编码长度，1或2字节 |
| `character` | 单个Unicode字符；未登记对应关系时为空 |
| `unicode` | 对应码点，如 `U+4E2D`；无确认对应时为空 |
| `glyph_label` | 已登记标签；特殊字形可能使用 `\small2\` 等名称 |
| `role` | 字位类别，区分普通映射、追加、界面别名及未登记字位 |
| `canonical_glyph_id` | 普通字位保留自身编号；界面专用别名指向对应的普通字位 |

换算关系：单字节字位的编码为 `glyph_id + 1`；双字节字位的编码为 `glyph_id + 0xA858`。`00`是原生空字节，不是编号0的字形。换行、结束及参数控制序列不属于本表的字形映射。

## 使用注意

- 同一Unicode字符可能对应多个字位，例如窄西文与双字节西文、普通字形与界面专用别名。不要合并、排序后重编或按Unicode去重。
- `decode.tbl`是解码对照，不是新文本的编码优先级表。新增中文界面文本使用已登记的双字节显示单元；紧凑底栏及日期别名仅用于各自界面。
- JSON以 `null` 表示缺少已确认的字符／码点，CSV对应单元格为空。原生特殊字形的命名标签不是若干ASCII字符组成的显示内容。
- CSV的编码列请按文本导入，避免表格软件把 `01` 等编码转成数字而丢失前导零；程序处理建议使用JSON。
