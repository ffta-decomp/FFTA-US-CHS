# FFTA-US-CHS

《最终幻想战略版 A2》美版（Nintendo DS）中文汉化补丁发布页。

当前正式版为 **1.0.6**，提供纯净版（clean）和增强版（plus）。增强版包含既有增强功能，以及「日版汉化体」「Z工坊圆」「文泉驿宋」三种可选字体。

- [下载 1.0.6 正式版补丁](https://github.com/ffta-decomp/FFTA-US-CHS/releases/tag/v1.0.6)
- [完整更新日志与模拟器兼容性](CHANGELOG.md)

本版订正职业解锁对白，调整文字间距并更新开屏。纯净版保留原有第一幕开屏；增强版默认显示三幕，后两幕可独立选择。

下载并解压 Release 中的 ZIP，用 Chrome、Edge 或 Safari 打开其中的离线 HTML 补丁工具。选择自己持有的 USA 原版 ROM，或补丁器列出的已支持旧汉化版；支持 `.nds` 文件和内含单个 `.nds` 文件的 ZIP。按页面说明选择版本与功能，生成新的游戏文件。

补丁处理在本机离线完成。升级前请备份游戏内普通存档，勿跨版本加载模拟器即时存档。本版尚未完成完整通关验证；历史版本的反馈和验证范围见更新日志。

本仓库仅提供用户文档和二进制汉化补丁，不提供游戏 ROM、存档、原始汉化脚本或素材。下载包包含离线 HTML 补丁工具、Release Log、汉化版使用声明和作者声明；署名、使用说明及第三方许可均在包内。
